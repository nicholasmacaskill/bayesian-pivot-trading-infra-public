# Plain Text Communication & No-LaTeX Formatting Rule

## Strict Prohibition: No LaTeX Math or Esoteric Symbols
* **NEVER** use LaTeX math formatting, equation delimiters (`$...$`, `$$...$$`), or math macro commands in chat responses or explanations.
* Examples of strictly prohibited syntax:
  - Do NOT write `$\ge$` or `\ge`.
  - Do NOT write `$\le$` or `\le`.
  - Do NOT write `$\to$` or `\to`.
  - Do NOT write `$\times$` or `\times`.
  - Do NOT write `$\text{...}$` or `\text{...}`.
  - Do NOT write `$\frac{a}{b}$` or `\frac`.
  - Do NOT write `$+2.8\text{R}$` or `$-1.0\text{R}$`.

## Required Plain English Formatting
* Always format numbers, comparisons, and relationships using clean, standard keyboard characters:
  - Write `>=` or "at least" / "greater than or equal to".
  - Write `<=` or "at most" / "less than or equal to".
  - Write `->` or "to".
  - Write `*` or `x` for multiplication.
  - Write `+2.8R`, `-1.0R`, `1.5R` directly without math blocks.
  - Write formulas in simple plain text (e.g., `MFE = (Peak - Entry) / Risk`).
* Keep tables, bullet points, and data summaries clean, plain, and immediately readable without confusing symbols or clutter.
